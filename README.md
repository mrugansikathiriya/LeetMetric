# 🚀 LeetMetric

🔗 **Live Demo:** [click here](https://mrugansikathiriya.github.io/LeetMetric/)

A web application that visualizes LeetCode statistics using the LeetCode GraphQL API. It displays difficulty-wise progress, submission counts, and an interactive dashboard.

## ✨ Features

- Search any public LeetCode username
- Difficulty-wise progress visualization
- Submission statistics
- Interactive circular progress bars

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- GraphQL

## ⚠️ Note

This project currently uses a public CORS proxy to access the LeetCode GraphQL API. The live demo may occasionally fail if the proxy service is unavailable or rate-limited.

## 🔮 Future Improvements

- Express.js backend to remove CORS dependency
- Contest statistics
- Better mobile responsiveness
